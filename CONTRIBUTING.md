# Contributing to Whitehat Runner

Thank you for your interest! This is a niche regex project, but improvements are welcome.

## How to help

- **Test the Runner** on various inputs and report issues.
- **New Ideas Are Welcomed!** If you have any ideas that might add to the functionality or easy-of-use, please feel free to say it!
- **Improve documentation** – examples, diagrams, performance notes.

## Before opening an issue

- Search existing issues.
- Provide a minimal failing input and expected output.

## Pull request process

1. Fork the repo.
2. Create a branch (`git checkout -b improve-runner`).
3. Make your changes.
4. Run tests (if any exist – we need test cases!).
5. Open a PR describing what you changed and why.
